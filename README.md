# Bankierstwo pana Scrooge'a

Interaktywna, samoprzewijająca się mapa wiktoriańskiego Londynu (1843) śladami pieniędzy Ebenezera Scrooge'a z „Opowieści wigilijnej” Dickensa. Obok mapy leci film z narracją Scrooge'a, a „Księga główna” zapisuje kolejne pozycje.

## Uruchomienie

```
node serve.js
```

Potem otwórz http://localhost:5180. Serwer obsługuje zapytania Range, więc film można przewijać.

## Sterowanie

- mapa płynie sama; pinezki i strzałki ← → przenoszą do przystanku
- spacja: pauza
- przeciąganie i kółko myszy: rozglądanie się po mapie (wycieczka wraca po kilku sekundach)
- przycisk głośnika: dźwięk filmu
